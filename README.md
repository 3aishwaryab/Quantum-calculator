# Quantum Calculator - A Unique Calculator Experience

A revolutionary calculator that combines advanced functionality with stunning visual design and innovative features. Built with Bootstrap 5, HTML, CSS, and JavaScript.

## 🌟 Unique Features

### 🎨 **Multiple Theme System**
- **Neon Theme**: Cyberpunk-inspired with glowing cyan and magenta effects
- **Matrix Theme**: Green-on-black terminal aesthetic
- **Solar Theme**: Warm orange and blue gradient design
- **Ocean Theme**: Deep blue aquatic color scheme

### 🧮 **Three Calculator Modes**
- **Basic Mode**: Standard arithmetic operations with memory functions
- **Scientific Mode**: Advanced mathematical functions (sin, cos, tan, log, ln, sqrt, powers, π)
- **Converter Mode**: Multi-unit converter for currency, length, weight, and temperature

### 📊 **Advanced Features**
- **Calculation History**: Track up to 50 recent calculations with timestamps
- **Memory Functions**: MR, MC, M+, M- with persistent memory display
- **Sound Feedback**: Unique audio tones for different button types
- **Keyboard Support**: Full keyboard navigation and shortcuts
- **Local Storage**: Saves settings, history, and memory between sessions

### 🎯 **Interactive Elements**
- **Animated Buttons**: Ripple effects and hover animations
- **Dynamic Display**: Shows current expression and result simultaneously
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Toggle Controls**: Show/hide history panel, mute/unmute sounds

## 🚀 Getting Started

1. Open `index.html` in any modern web browser
2. The calculator loads with your previous settings and history
3. Use mouse/touch or keyboard to perform calculations

## ⌨️ Keyboard Shortcuts

| Key | Function |
|-----|----------|
| 0-9 | Number input |
| . | Decimal point |
| +, -, *, /, % | Operators |
| Enter, = | Calculate result |
| Escape, C | Clear all |
| Backspace | Delete last digit |
| (, ) | Parentheses (Scientific mode) |
